# nx-ovlloader 2.0.3-deko3d

- В исходном manifest заданы пул Applet, тип программы Applet и MapRange дисплея 0x54200000–0x5427FFFF.
- Оверлеям deko3d доступна дополнительная память видеочипа для живого размытия.
- Сохраняется title ID 420000000007E51A; в комплект входят перезагрузчик и его sysmodule.
- Добавлена проверка прав в скомпилированном NPDM перед упаковкой.

Используйте с Ryzhand 2.5.2 и оверлеями -deko3d, адаптированными для событий UEvent. Старые оверлеи, создающие события ядра, требуют обновления. Распакуйте nx-ovlloader.zip в корень SD-карты и полностью перезагрузите консоль.
